# 1 rest (sit down, src/bonfire.c): a killed enemy (1020160, graveyard) is back with full HP, HP and Estus refilled
#   (10: Firelink is kindled to 20 points by 2009[03]), respawn point = the bonfire's spawn point (1021960 + 1000), last
#   bonfire 1021960; then leave the menu (stand up).
# 2 lethal fall off the east cliff (as save_death.txt): bloodstain with the 500 souls held where the player last stood,
#   souls 0, back at the spawn point 復活ポイント00 (-47.4 -59.8 53.3), full HP, the enemy killed again is back.
# 3 the stain survives a save round trip; walking onto it gives the souls back.
# 4 death on the ground (hurt) by the bonfire: the ESD death anim, then the respawn; the new stain lies there.
#   rm -f build/save/a4test*.bin  # a save from an earlier run carries its deaths count
#   tools/q -m 4 python3 tools/test-run.py build/proto.sym.elf ps2/proto/tests/a4_rest_death.txt build/test/a4
